۱ Django چیه و چرا؟

۱.۱ داستان Django

Django یه فریم‌ورک وب پایتونیه. فرض کن می‌خوای یه مغازه باز کنی. دو راه داری: از صفر آجر و سیمان بخری و دیوار بچینی، یا یه ساختمون آماده اجاره کنی که همه چیز توش هست. Django راه دوم رو بهت می‌ده.

Django همه چیز داره: سیستم دیتابیس، لاگین، پنل ادمین، مدیریت فرم، امنیت، URL routing.

۱.۲ معماری MVT

تصور کن یه رستوران داری:

بخشتوی رستورانتوی Djangoکارش
Modelانبارmodels.pyنگه‌داری داده‌ها
Viewآشپزviews.pyپردازش منطق
Templateبشقاب.htmlنمایش به مشتری

URL هم می‌شه گارسون: مشتری (کاربر) سفارش می‌ده، گارسون (URL) می‌بره به آشپز (View)، آشپز از انبار (Model) مواد می‌گیره، غذا رو توی بشقاب (Template) می‌ذاره، گارسون برمی‌گردونه.

۱.۳ جریان یک درخواست (کامل)

۱. کاربر توی مرورگر می‌زنه: /products/iphone/
                                                       ↓
۲. مرورگر درخواست (Request) می‌فرسته به سرور
                                                       ↓
۳. Django می‌ره توی config/urls.py:
   - دنبال الگویی می‌گرده که با /products/iphone/ بخوره
   - پیدا می‌کنه: path('products/<slug:slug>/', ...)
   - می‌فهمه باید بره به ProductDetailView
                                                       ↓
۴. Django می‌ره توی shop/views.py:
   - کلاس ProductDetailView رو اجرا می‌کنه
   - DetailView خودش می‌ره مدل Product رو صدا می‌زنه
                                                       ↓
۵. مدل Product می‌ره توی دیتابیس:
   SELECT * FROM shop_product WHERE slug = 'iphone'
                                                       ↓
۶. دیتابیس آبجکت Product رو برمی‌گردونه
                                                       ↓
۷. View این آبجکت رو می‌ذاره توی context:
   context = {'product': <Product: iPhone>}
                                                       ↓
۸. View می‌ره تمپلیت shop/product.html رو پیدا می‌کنه
                                                       ↓
۹. تمپلیت اجرا می‌شه: HTML نهایی ساخته می‌شه
                                                       ↓
۱۰. HTML برمی‌گرده به مرورگر کاربر

۲ ساختار پروژه

۲.۱ Project vs App

Project = کل ساختمون. App = یه واحد از ساختمون. یه Project می‌تونه چند App داشته باشه: shop، blog، users.

۳ مدل‌ها (Models)

۳.۱ مدل چیه؟

مدل = کلاس پایتون که به جدول دیتابیس تبدیل می‌شه. بدون نوشتن SQL، جدول می‌سازی. 

class Product(models.Model):
    title = models.CharField(max_length=255)

تبدیل می‌شه به:

CREATE TABLE shop_product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(255) NOT NULL
);

۳.۲ مدل کامل با توضیح خط به خط

from django.db import models              # خط ۱: وارد کردن ماژول models
from django.utils.text import slugify     # خط ۲: تابع slugify
from django.urls import reverse           # خط ۳: تابع reverse
from decimal import Decimal               # خط ۴: کلاس Decimal

class Product(models.Model):              # خط ۵: کلاس Product که از Model ارث می‌بره
    title = models.CharField(max_length=255)                       # خط ۶
    slug = models.SlugField(blank=True)                            # خط ۷
    description = models.TextField()                               # خط ۸
    stash = models.PositiveSmallIntegerField(default=0)            # خط ۹
    price = models.DecimalField(max_digits=12, decimal_places=2)   # خط ۱۰
    image = models.ImageField(upload_to='product/', null=True, blank=True)  # خط ۱۱
    created = models.DateTimeField(auto_now_add=True)              # خط ۱۲
    updated = models.DateTimeField(auto_now=True)                  # خط ۱۳

    def save(self, *args, **kwargs):      # خط ۱۴
        if not self.slug:                  # خط ۱۵
            self.slug = slugify(self.title)  # خط ۱۶
        return super().save(*args, **kwargs)  # خط ۱۷

    def __str__(self):                     # خط ۱۸
        return self.title                  # خط ۱۹

    def get_absolute_url(self):            # خط ۲۰
        return reverse('product_detail', kwargs={'slug': self.slug})  # خط ۲۱
توضیح خط به خط
  • خط ۱: ماژول models رو وارد می‌کنیم
  • خط ۲: تابع slugify که متن رو URL-friendly می‌کنه: "iPhone 15" → "iphone-15"
  • خط ۳: reverse برای ساخت URL از روی اسم
  • خط ۴: Decimal برای اعداد اعشاری دقیق (برای پول حتماً Decimal نه float!)
  • خط ۵: کلاس Product که از Model ارث می‌بره (بدون این جدول نمی‌شه)
  • خط ۶: فیلد متن کوتاه حداکثر ۲۵۵ کاراکتر
  • خط ۷: فیلد Slug برای URL. blank=True یعنی توی فرم می‌تونه خالی باشه
  • خط ۸: فیلد متن بلند (TEXT)
  • خط ۹: عدد صحیح مثبت کوچک، پیش‌فرض صفر
  • خط ۱۰: عدد اعشاری دقیق (۱۲ رقم کل، ۲ رقم اعشار)
  • خط ۱۱: فیلد تصویر. فایل‌ها می‌رن توی media/product/
  • خط ۱۲: زمان ساخت. فقط یک بار موقع اولین save ست می‌شه
  • خط ۱۳: زمان آپدیت. هر بار save تغییر می‌کنه
  • خط ۱۴: override متد save
  • خط ۱۵: اگه slug خالی بود
  • خط ۱۶: از title یه slug بساز
  • خط ۱۷: متد save والد رو صدا بزن (ذخیره کن)
  • خط ۱۸: متد __str__ برای نمایش زیبا
  • خط ۱۹: عنوان محصول رو برگردون
  • خط ۲۰: متد URL اختصاصی آبجکت
  • خط ۲۱: URL صفحه محصول رو بساز

۳.۴ null و blank - تفاوت مهم

⚠️ تفاوت حیاتی
  • null=True: سطح دیتابیس (SQL: NULL مجاز)
  • blank=True: سطح فرم (کاربر می‌تونه خالی بذاره)

برای فیلدهای متنی معمولاً blank=True (نه null). برای تاریخ و ForeignKey null=True, blank=True.

۳.۵ روابط

ForeignKey (یک-به-چند)

class Comment(models.Model):
    product = models.ForeignKey(
        Product,                       # به کدوم مدل
        on_delete=models.CASCADE,      # وقتی محصول حذف شد چی بشه
        related_name='comments'        # دسترسی معکوس
    )
    author = models.CharField(max_length=255)
    description = models.TextField()

on_delete گزینه‌ها:

  • CASCADE: کامنت‌ها هم پاک بشن
  • PROTECT: اجازه حذف نده
  • SET_NULL: بشه NULL (نیاز به null=True)
  • SET_DEFAULT: بشه پیش‌فرض
  • DO_NOTHING: هیچی (خطرناک)

related_name:

  • بدونش: product.comment_set.all()
  • با related_name='comments': product.comments.all()

OneToOneField (یک-به-یک)

class Cart(models.Model):
    user = models.OneToOneField(
        User,
        on_delete=models.CASCADE,
        related_name='cart'
    )

هر کاربر فقط یک سبد. دسترسی: user.cart

ManyToManyField (چند-به-چند)

class Product(models.Model):
    tags = models.ManyToManyField('Tag', related_name='products')

هر محصول چند تگ، هر تگ چند محصول. دسترسی: product.tags.all()

class TimeStampMixin(models.Model):
    created = models.DateTimeField(auto_now_add=True)
    updated = models.DateTimeField(auto_now=True)

    class Meta:
        abstract = True   # جدول جدا نمی‌سازه

# استفاده:
class Product(TimeStampMixin):

۳.۷ @property - فیلد محاسباتی

class Cart(models.Model):
    @property
    def total_price(self):
        return sum(
            item.product.price * item.quantity
            for item in self.items.all()
        )

توی تمپلیت: {{ cart.total_price }} (بدون پرانتز)

۴ ORM - کار با دیتابیس

ORM = Object-Relational Mapping. پل بین پایتون و دیتابیس. بدون SQL می‌تونی کار کنی.

۴.۱ CRUD

# Create - ساخت
p = Product.objects.create(title='iPhone', price=1000)

# Read - خوندن
p = Product.objects.get(id=1)                  # یکی (خطا اگه نباشه)
p = Product.objects.filter(price__gt=500)      # چند تا
p = Product.objects.all()                       # همه
p = Product.objects.first()                     # اولی
p = Product.objects.count()                     # تعداد

# Update - ویرایش
p.price = 1200
p.save()                                      # حتماً save

# Delete - حذف
p.delete()

۴.۲ Lookups (فیلترها)

Lookupمعنیمثال
exactمساویfilter(title__exact='iPhone')
iexactمساوی (بدون حساسیت)filter(title__iexact='iphone')
gtبزرگ‌ترfilter(price__gt=500)
gteبزرگ‌تر مساویfilter(price__gte=500)
ltکوچک‌ترfilter(price__lt=500)
lteکوچک‌تر مساویfilter(price__lte=500)
inتوی لیستfilter(id__in=[1,2,3])
containsشاملfilter(title__contains='iPhone')
icontainsشامل (بدون حساسیت)filter(title__icontains='iphone')
startswithشروع باfilter(title__startswith='iP')
endswithپایان باfilter(title__endswith='15')
rangeبازهfilter(price__range=(100, 500))
isnullNULL هستfilter(image__isnull=True)

products = (Product.objects

qs = Product.objects.all()          # هنوز به دیتابیس نرفته

۴.۷ Q و F Objects

from django.db.models import Q, F

# Q برای OR/AND پیچیده
Product.objects.filter(Q(price__lt=100) | Q(stash__gt=0))

# F برای مقایسه فیلدها
Product.objects.filter(stash__gt=F('sold'))
Product.objects.update(price=F('price') * 1.1)  # ۱۰٪ افزایش

۴.۸ بهینه‌سازی - N+1 Problem

# ❌ بد: ۱۰۱ تا query
products = Product.objects.all()          # ۱ query
for p in products:
    print(p.comments.count())              # ۱۰۰ query اضافی

# ✅ خوب: ۲ query
products = Product.objects.prefetch_related('comments')
cart = Cart.objects.select_related('user').get(pk=1)
💡 قانون طلایی
  • select_related('fk') برای ForeignKey و OneToOne
  • prefetch_related('reverse_fk') برای ManyToMany و Reverse

۶ Views

View = تابع یا کلاسی که یه Request می‌گیره و یه Response برمی‌گردونه.

۶.۱ دو نوع ویو

FBV - Function-Based View (تابعی) 
from django.shortcuts import render

def product_list(request):
    products = Product.objects.all()
    return render(request, 'shop/products.html', {'products': products})
CBV - Class-Based View (کلاسی) 
class ProductListView(ListView):

۶.۴ DetailView

class ProductDetailView(DetailView):
    model = Product
    slug_field = 'slug'                # با کدوم فیلد جستجو کنه
    slug_url_kwarg = 'slug'            # اسم پارامتر در URL
    context_object_name = 'product'
    template_name = 'shop/product.html'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)  # context پایه
        context['form'] = CommentForm()                # اضافه کن
        context['cart_form'] = AddProductToCartForm()
        return context

۶.۷ dispatch - خط به خط

class CartListView(ListView):
    def dispatch(self, request, *args, **kwargs):
        if not request.user.is_staff:      # اگه ادمین نیست
            raise PermissionDenied          # خطای 403
        return super().dispatch(request, *args, **kwargs)

dispatch اولین متدی است که برای هر HTTP method اجرا می‌شه.

۶.۸ form_valid با commit=False

def form_valid(self, form):
    obj = form.save(commit=False)     # ذخیره نکن
    product = get_object_or_404(Product, slug=self.kwargs['slug'])
    obj.product = product             # محصول رو وصل کن
    return super().form_valid(form)   # حالا ذخیره کن

def create_order_from_cart(cart, order):

class TimeStampMixin(models.Model):
    created = models.DateTimeField(auto_now_add=True)
    updated = models.DateTimeField(auto_now=True)

    class Meta:
        abstract = True                # جدول جدا نمی‌سازه


class Product(TimeStampMixin):
    title = models.CharField(max_length=255)
    slug = models.SlugField(blank=True)
    description = models.TextField()
    stash = models.PositiveSmallIntegerField(default=0)
    price = models.DecimalField(max_digits=12, decimal_places=2)
    image = models.ImageField(upload_to='product/', null=True, blank=True)

    def save(self, *args, **kwargs):
        if not self.slug:
            self.slug = slugify(self.title)
        return super().save(*args, **kwargs)

    def __str__(self):
        return self.title

    def get_absolute_url(self):
        return reverse('product_detail', kwargs={'slug': self.slug})


class Comment(models.Model):
    product = models.ForeignKey(
        Product, on_delete=models.CASCADE, related_name='comments'
    )
    author = models.CharField(max_length=255)
    description = models.TextField()

    def __str__(self):
        return f'{self.author} - {self.product}'


class Cart(TimeStampMixin):
    user = models.OneToOneField(User, on_delete=models.CASCADE, related_name='cart')

    @property
    def total_price(self):
        return sum(
            item.product.price * item.quantity
            for item in self.items.all()
        )


class CartItem(TimeStampMixin):
    cart = models.ForeignKey(Cart, on_delete=models.CASCADE, related_name='items')
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    quantity = models.PositiveSmallIntegerField(default=1)


class Order(TimeStampMixin):
    class StatusChoices(models.TextChoices):
        PENDING = 'pend', 'در انتظار'
        PAID = 'paid', 'پرداخت شده'
        CANCEL = 'c', 'لغو شده'

    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='orders')
    final_price = models.DecimalField(max_digits=12, decimal_places=2, default=Decimal('0.00'))
    status = models.CharField(max_length=4, choices=StatusChoices.choices, default=StatusChoices.PENDING)


class OrderItem(TimeStampMixin):
    order = models.ForeignKey(Order, on_delete=models.CASCADE, related_name='items')
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    quantity = models.PositiveIntegerField(default=1)

class CommentCreateView(LoginRequiredMixin, CreateView):
    model = Comment
    form_class = CommentForm
    template_name = 'shop/comment-create.html'

    def get_success_url(self):
        return reverse('product_detail', kwargs={'slug': self.kwargs['slug']})

    def form_valid(self, form):
        obj = form.save(commit=False)
        product = get_object_or_404(Product, slug=self.kwargs['slug'])
        obj.product = product
        return super().form_valid(form)


class CartAddView(LoginRequiredMixin, View):
    def post(self, request, product_id):
        form = AddProductToCartForm(request.POST)
        product = get_object_or_404(Product, pk=product_id)

        if form.is_valid():
            cart, _ = Cart.objects.get_or_create(user=request.user)  # ← فیلتر!
            CartItem.objects.create(
                cart=cart,
                product=product,
                quantity=form.cleaned_data['quantity']
            )
        return redirect('product_list')


class CreateOrderView(LoginRequiredMixin, View):
    def post(self, request, pk):
        cart = get_object_or_404(Cart, pk=pk, user=request.user)
        order = Order.objects.create(user=request.user)
        create_order_from_cart(cart=cart, order=order)
        cart.items.all().delete()  # سبد رو خالی کن
        return redirect('order_detail', pk=order.pk)
